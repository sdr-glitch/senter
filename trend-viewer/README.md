# 📈 트렌드 뷰어 — 센터 로컬 도구

관심 키워드의 **최신 뉴스**와 **실시간 급상승 검색어**(구글 트렌드·한국)를 한 화면에 모아주는 내 컴퓨터용 도구예요.
콘텐츠 소재 찾기·시즌 이슈 선점에 쓰세요. 데이터는 `data/` 폴더에만 저장됩니다.

## 사용법 (딱 2단계)

1. **Node.js 설치** (한 번만): https://nodejs.org 에서 LTS 버전 다운로드 → 설치
2. 이 폴더의 **`시작하기.command`**(맥) 또는 **`시작하기.bat`**(윈도우) 더블클릭
   → 브라우저가 자동으로 열려요 (안 열리면 주소창에 `http://localhost:8799`)

끄려면 함께 열린 검은 창을 닫으면 됩니다.

## 무엇이 되나요?

- 🔥 실시간 급상승 검색어 (10분마다 자동 갱신)
- 🔍 관심 키워드 등록(최대 12개) → 키워드별 최신 뉴스 8개
- 키워드별 바로가기: 네이버 데이터랩 · 구글 트렌드 · 인스타 태그 · 유튜브 · 네이버 쇼핑

## 센터 웹앱과 함께 쓰는 법

여기서 발견한 트렌드/뉴스 내용을 복사해서 → 센터 웹앱 **자료실**에 붙여넣으면,
직원들이 스터디 회의를 열고 다음 콘텐츠 기획에 자동으로 반영해요.

## 문제 해결

- **급상승이 안 떠요**: 구글이 주소를 바꿨거나 네트워크가 막힌 경우예요. 키워드 뉴스는 별도 경로라 대부분 정상 작동합니다.
- **회사 네트워크(프록시)**: `HTTPS_PROXY` 환경변수를 자동 인식합니다.
- **포트 충돌**: `PORT=9000 node server.js` 처럼 바꿔 실행하세요.
