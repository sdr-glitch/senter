## 🚀 사용 방법 (코딩 몰라도 OK)

### 1단계. 앱 열기

**방법 A — 인터넷 주소로 쓰기 (추천)**
1. 이 GitHub 저장소 페이지에서 **Settings** 클릭
2. 왼쪽 메뉴에서 **Pages** 클릭
3. "Branch"에서 브랜치를 선택하고 **Save**
4. 1~2분 뒤 `https://(내아이디).github.io/senter/` 주소가 생겨요 — 즐겨찾기 해두고 쓰면 됩니다. 휴대폰에서도 열려요!

**방법 B — 내 컴퓨터에서 바로 열기**
1. 저장소 첫 화면에서 초록색 **Code** 버튼 → **Download ZIP**
2. 압축을 풀고 `index.html` 파일을 더블클릭

### 2단계. AI 연결하기 (딱 한 번만)

이 앱의 멘토들은 **Claude**라는 AI를 사용해요. 열쇠(API 키)를 한 번만 등록하면 됩니다.

1. [console.anthropic.com](https://console.anthropic.com/) 접속 → 회원가입 (구글 계정 가능)
2. **Billing**(결제) 메뉴에서 카드 등록 후 **$5 충전** (약 7천 원 — 가볍게 쓰면 몇 달 갑니다)
3. **API Keys** 메뉴 → **Create Key** → 생성된 `sk-ant-...` 키를 **복사**
4. 앱의 ⚙️ 설정 탭에 붙여넣고 저장

> 🔒 키는 내 브라우저에만 저장되고 다른 곳으로 전송되지 않아요.
> 💰 비용은 쓴 만큼만: 대화 한 번에 몇 원~몇십 원 수준이에요.

### 3단계. 자료 학습시키기

1. 📚 **자료실** 탭 → **붙여넣기로 추가**
2. 노션에 정리한 강의 노트를 열고 → 전체 선택(`Ctrl+A`) → 복사(`Ctrl+C`) → 앱에 붙여넣기
3. 이제 모든 멘토가 그 자료를 참고해서 대답해요!

`.txt`, `.md` 파일 업로드도 됩니다. (PDF는 내용을 복사해서 붙여넣어 주세요)

## ❓ 자주 묻는 질문

**Q. 데이터는 어디에 저장되나요?**
전부 내 브라우저 안에만 저장돼요. 다른 컴퓨터/브라우저로 옮길 땐 설정 탭의 **백업 내보내기/불러오기**를 쓰세요.

**Q. 무료로는 못 쓰나요?**
앱 자체는 무료지만, AI 답변에는 API 사용료가 들어요(쓴 만큼만). 절약하려면 설정에서 모델을 **Haiku**로 바꾸면 비용이 크게 줄어요.

**Q. "API 키가 올바르지 않아요"라고 나와요.**
키를 복사할 때 앞뒤 공백이 붙었을 수 있어요. 설정에서 지우고 다시 붙여넣어 보세요. 그래도 안 되면 console.anthropic.com에서 새 키를 만들어 주세요.

**Q. 대답이 안 오고 "크레딧 부족"이 떠요.**
console.anthropic.com의 Billing에서 잔액을 확인하고 충전해 주세요.

## 🛠️ 기술 정보 (개발자용)

- 순수 HTML/CSS/JavaScript — 빌드·서버·설치 불필요, 정적 호스팅이면 어디서든 동작

- 모든 데이터는 `localStorage`에 저장 (접두사 `senter:`)
- 파일 구성: `index.html`(구조) · `style.css`(디자인) · `app.js`(로직)
