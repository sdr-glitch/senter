🔑 AI 연결하기 (API 키 발급)

이 앱의 AI 멘토는 Claude(클로드)라는 AI를 사용해요. 사용하려면 "API 키"라는 열쇠가 필요합니다. 쓴 만큼만 소액 결제되는 방식이에요 (가볍게 쓰면 월 몇천 원 수준).

  1. console.anthropic.com 에 접속해서 회원가입 (구글 계정으로 가능)
  2. 왼쪽 메뉴 또는 설정에서 Billing(결제)에 들어가 카드 등록 후 $5 정도 충전 (약 7천 원 — 몇 달은 씁니다)
  3. API Keys 메뉴에서 Create Key 클릭 → 이름은 아무거나 (예: senter)
  4. sk-ant- 로 시작하는 긴 문자가 나오면 복사 (이 화면을 벗어나면 다시 볼 수 없으니 꼭 복사!)
  5. 아래 칸에 붙여넣기 → 저장

🔒 키는 이 브라우저에만 저장되며, 외부 서버로 전송되지 않아요 (AI 호출 시 Anthropic에만 전달).
