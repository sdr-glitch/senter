필요한 부분만 복사:
🛠 살짝 고치기 — 처음부터 다시 안 만들어도 돼요. 원하는 것만 콕 집어서!
📖 이 대본, 캡컷·프리미어에 어떻게 넣나요? (처음이라면 열어보세요)
✂️ 캡컷 (무료, 폰·PC)
  1. 새 프로젝트 → 올렸던 사진·영상을 컷 편집표 순서대로 추가
  2. 컷 편집표의 시간에 맞춰 클립을 분할(자르기) — 타임라인에서 클립 선택 → 분할
  3. 텍스트 → 자막 가져오기에서 방금 저장한 자막.srt 선택 (또는 '자동 캡션'으로 나레이션 인식)
  4. 오디오에서 대본의 BGM 키워드로 음악 검색 → 비트에 컷 맞추기
  5. 내보내기: 해상도 1080p · 프레임 30 → 릴스/쇼츠 업로드!
🎞️ 프리미어 프로 (PC)
  1. 새 시퀀스 → 사전 설정에서 세로(1080×1920) 선택
  2. 소스를 타임라인에 배치하고 컷 편집표 시간대로 자르기(C 키)
  3. 상단 텍스트 → 캡션 → 캡션 가져오기로 자막.srt 넣기 (또는 '음성을 텍스트로'로 자동 자막)
  4. 나레이션은 대본 보면서 보이스오버 녹음(타임라인 마이크 버튼)
  5. 내보내기: H.264 · 1080×1920 · 30fps

📜 최근 활동

🧑‍💼 나의 AI 직원 사무실

결제·API 키 없이 지금 바로 무료로 쓰는 방법이에요. 각 직원의 "업무 지시서"를 복사해서 무료 AI 챗봇에 붙여넣으면, 그 대화방이 나만의 전문 직원이 됩니다. 지시서에는 내 계정 정보가 자동으로 들어가 있어요.

  1. 아래에서 직원을 골라 [업무 지시서 복사] 클릭
  2. 무료 AI 챗봇을 열기 — Gemini · ChatGPT · Claude (전부 무료 가입 가능)
  3. 새 대화에 붙여넣기 → 직원이 "출근했습니다!" 인사를 하면 일 시키기 시작!
💡 직원을 일 잘하게 만드는 3가지 규칙
① 직원 1명 = 대화방 1개를 계속 사용하세요 (대화방이 직원의 기억이에요. 방 이름도 "카피라이터"로 바꿔두기)
② 결과가 마음에 안 들면 "다시 해줘" 대신 "○○ 부분을 △△하게 바꿔줘"처럼 구체적으로 피드백하세요
③ 잘 나온 결과물은 "앞으로 이 스타일 유지해줘"라고 말해서 기준으로 굳히세요

🏢 조직도 — 결재선

팀원이 초안을 쓰면(저렴한 모델) → 팀장이 검토·수정하고 팀 회의(상위 모델) → 과장이 전체 회의 후 최종 보고서(상위 모델) → 사장님이 승인해요. 토큰은 아끼고 품질은 위에서 챙기는 구조예요.

➕ 새 직원 채용하기

필요한 직원을 직접 채용하세요. 채용하면 사무실 책상·회의 좌석·업무 배정까지 자동으로 반영됩니다. (예: "블로그 작가 — 네이버 블로그 글 작성 담당")
