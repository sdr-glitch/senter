🔑 AI 연결하기 (API 키 발급)

이 앱의 AI 멘토는 Claude(클로드)라는 AI를 사용해요. 사용하려면 "API 키"라는 열쇠가 필요합니다. 쓴 만큼만 소액 결제되는 방식이에요 (가볍게 쓰면 월 몇천 원 수준).

  1. console.anthropic.com 에 접속해서 회원가입 (구글 계정으로 가능)
  2. 왼쪽 메뉴 또는 설정에서 Billing(결제)에 들어가 카드 등록 후 $5 정도 충전 (약 7천 원 — 몇 달은 씁니다)
  3. API Keys 메뉴에서 Create Key 클릭 → 이름은 아무거나 (예: senter)
  4. sk-ant- 로 시작하는 긴 문자가 나오면 복사 (이 화면을 벗어나면 다시 볼 수 없으니 꼭 복사!)
  5. 아래 칸에 붙여넣기 → 저장

🔒 키는 이 브라우저에만 저장되며, 외부 서버로 전송되지 않아요 (AI 호출 시 Anthropic에만 전달).

🎯 지시 내리기

할 일을 한 줄로 지시하면 매니저가 담당 직원에게 배정하고 업무 카드를 만들어요. (예: "이번 주 릴스 3개 기획해줘", "체험단 지원 문구 만들어줘")

📊 업무 현황판

모든 업무는 3단계 품질 검증을 거쳐 보고됩니다: ① 담당자 초안 → ② 전문가 2명의 1차 교차검증 후 수정·재검토 → ③ 매니저 3차 최종 검토 → 보고. API 키가 없을 땐 각 단계의 [지시서 복사] → 무료 AI에 붙여넣기 → 결과를 제출하면 다음 단계로 넘어가요. (API 키 연결 시 전 과정 자동)

📜 최근 활동

🧑‍💼 나의 AI 직원 사무실

결제·API 키 없이 지금 바로 무료로 쓰는 방법이에요. 각 직원의 "업무 지시서"를 복사해서 무료 AI 챗봇에 붙여넣으면, 그 대화방이 나만의 전문 직원이 됩니다. 지시서에는 내 계정 정보가 자동으로 들어가 있어요.

  1. 아래에서 직원을 골라 [업무 지시서 복사] 클릭
  2. 무료 AI 챗봇을 열기 — Gemini · ChatGPT · Claude (전부 무료 가입 가능)
  3. 새 대화에 붙여넣기 → 직원이 "출근했습니다!" 인사를 하면 일 시키기 시작!
💡 직원을 일 잘하게 만드는 3가지 규칙
① 직원 1명 = 대화방 1개를 계속 사용하세요 (대화방이 직원의 기억이에요. 방 이름도 "카피라이터"로 바꿔두기)
② 결과가 마음에 안 들면 "다시 해줘" 대신 "○○ 부분을 △△하게 바꿔줘"처럼 구체적으로 피드백하세요
③ 잘 나온 결과물은 "앞으로 이 스타일 유지해줘"라고 말해서 기준으로 굳히세요

➕ 새 직원 채용하기

필요한 직원을 직접 채용하세요. 채용하면 사무실 책상·회의 좌석·업무 배정까지 자동으로 반영됩니다. (예: "블로그 작가 — 네이버 블로그 글 작성 담당")
