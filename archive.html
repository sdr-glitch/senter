📦 노션과 연결하기

딱 3단계면 끝나요. 한 번만 해두면 이 페이지가 노션 데이터베이스를 계속 지켜보면서 자동으로 새 내용을 보여줘요.

1단계 — 노션 '연결 열쇠(토큰)' 만들기

  1. notion.so/my-integrations 열기 (노션 로그인 필요)
  2. + 새 API 통합 만들기 클릭 → 이름은 아카이브 등 아무거나
  3. 내 워크스페이스 선택 → 저장
  4. 프라이빗 API 통합 시크릿의 표시 → 복사 후 아래에 붙여넣기

2단계 — 데이터베이스에 열쇠 꽂아주기

노션에서 연동할 데이터베이스 페이지를 열고 → 오른쪽 위 ⋯ → 연결(Connections) → 방금 만든 통합 이름(아카이브)을 검색해 선택하세요. 이걸 안 하면 "찾을 수 없음" 오류가 나요.

💡 「📦 나의 아카이브」라는 시작용 데이터베이스를 이미 만들어 뒀어요 — 노션 검색창에서 찾아 쓰면 돼요.

3단계 — 데이터베이스 링크 붙여넣기

데이터베이스 페이지에서 ⋯ → 링크 복사 한 주소를 그대로 붙여넣으세요.

⚙️ 연결 설정

열쇠(토큰)와 링크는 이 브라우저에만 저장돼요. 주소 복사로 만든 링크에는 절대 포함되지 않아요.

고급 — 연결이 자꾸 실패할 때

노션은 웹페이지가 직접 데이터를 가져가는 걸 막아서, 중간에 무료 중계 서버를 거쳐요. 기본 중계 서버가 모두 막히면 아래에 나만의 중계 주소를 넣을 수 있어요 (Cloudflare Workers 등에서 CORS 프록시를 만들어 붙여넣기).

🎨 내 마음대로 꾸미기

고르는 즉시 화면에 바로 적용돼요. 완성한 색은 「내 주소」 링크에도 함께 담겨요.

🔗 나만의 주소 만들기

아카이브의 이름·이모지·주소 이름을 정하면 나만의 고유 주소가 완성돼요. 이 주소를 즐겨찾기 해두면 어디서든 내 색깔 그대로 열려요.

주소 앞부분(도메인)도 바꾸고 싶다면?

GitHub Pages 주소는 https://아이디.github.io/저장소이름/archive.html 구조예요.

  1. 저장소 이름을 바꾸면 가운데 부분이 바뀌어요 (GitHub → Settings → Repository name)
  2. 파일 이름(archive.html)을 바꾸면 마지막 부분이 바뀌어요
  3. 완전한 나만의 주소(예: archive.jaea.com)는 GitHub → Settings → Pages → Custom domain에서 내 도메인을 연결하면 돼요 (도메인 구입 필요)
