# Claude Desk

터미널을 몰라도 쓸 수 있는, **팀을 위한 Claude Code 웹 데스크**입니다.
버튼 하나로 자동화를 실행하고, 일일 리포트를 만들고, 슬랙으로 공유하고,
할 일·캘린더·메모·집중 타이머까지 한 화면에서 관리합니다.

- 설치할 라이브러리 없음 (Node.js 내장 기능만 사용, `npm install` 불필요)
- 모든 데이터는 이 폴더의 `data/` 안에만 저장 (외부 전송 없음 · 슬랙 알림은 직접 켠 경우만)

---

## 🚀 팀원용: 그냥 쓰는 법

1. 폴더 안의 **`시작하기.command`**(맥) 또는 **`시작하기.bat`**(윈도우)를 더블클릭
2. 브라우저가 자동으로 열립니다 (안 열리면 주소창에 `http://localhost:8787`)
3. 원하는 버튼을 누르면 끝! 진행 상황이 화면 아래에 실시간으로 보입니다.
4. 앱을 끄려면 함께 열린 검은 창(터미널)을 닫으세요. 데이터는 모두 남습니다.

> 💡 화면 왼쪽 아래 **"❓ 처음이신가요?"** 를 누르면 1분 사용법이 나옵니다.

---

## 🔧 관리자용: 최초 1회 설정

팀에서 한 명(관리자)만 아래를 진행하면 됩니다.

1. **Node.js 18 이상 설치** — https://nodejs.org (LTS 버전)
2. **Claude Code 설치** — 터미널에서:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```
3. **로그인** — 터미널에서 `claude` 실행 후 안내에 따라 로그인 (Claude Pro/Max 구독 또는 Console 계정)
4. 이 폴더를 팀원 컴퓨터에 복사하고, 각 컴퓨터에서 2–3번을 반복
5. 앱 실행 → **설정 → 작업 폴더**에 팀 프로젝트 경로 입력

버전 확인: `claude --version` / 공식 문서: https://code.claude.com/docs

## 화면 안내

| 탭 | 하는 일 |
|---|---|
| ⚡ 자동화 버튼 | 원클릭 자동화 실행 + 오늘 요약 위젯 + 직접 요청 |
| 📋 일일 리포트 | 리포트 생성·열람·`.md` 저장. 자동 생성 스케줄 지원 |
| 🗂️ 세션 기록 | 모든 실행 기록. 열어서 **이어서 질문** 가능, 복사/저장 지원 |
| ✅ 할 일 | 체크박스 할 일 + 마감일 + 🧠 Claude 우선순위 추천 |
| 🗓️ 캘린더 | 월간 달력, 날짜 클릭으로 일정 추가 |
| 📝 메모 | 빠른 메모 + ✨ Claude로 정리하기 |
| ⏱️ 집중 타이머 | 뽀모도로 타이머. 할 일 연결·완료 알림·집중 기록 통계 |
| ⚙️ 설정 | 작업 폴더 / 슬랙 / 자동 생성 / 버튼 관리 |

## 🔔 슬랙 알림 연동

1. 슬랙 워크스페이스 관리자에게 **Incoming Webhook** 주소를 받습니다.
   - 슬랙에서 직접 만들기: https://api.slack.com/apps → Create App →
     **Incoming Webhooks** 켜기 → 알림 받을 채널 선택 → Webhook URL 복사
2. Claude Desk **설정 → 슬랙 알림**에 주소를 붙여 넣고 저장
3. **테스트 발송**을 눌러 채널에 메시지가 오는지 확인
4. 원하는 알림을 선택:
   - **일일 리포트 알림**: 리포트가 만들어질 때마다 (기본 켬)
   - **모든 작업 알림**: 모든 버튼 실행의 완료/실패

## ⏰ 일일 리포트 자동 생성

**설정 → 일일 리포트 자동 생성**에서 켜고 시간을 정하세요 (평일만/매일 선택 가능).

- 앱이 **켜져 있는 동안** 30초마다 확인해서, 정한 시간이 되면 자동으로 만듭니다.
- 컴퓨터/앱이 꺼져 있었다면? 다음에 앱을 켤 때 "아직 오늘 리포트가 없네" 하고 만들어 줍니다.
- 하루에 한 번만 만들어지며, 슬랙 알림을 켜 두면 완성 즉시 채널로 공유됩니다.

## 새 자동화 버튼 만들기

**설정 → 자동화 버튼 관리 → 새 버튼**에서:

- **요청 내용**: Claude에게 시킬 일을 평소 말하듯 적으세요. `{DATE}`는 실행 날짜로 치환됩니다.
- **권한 수준**:
  - *읽기만* (권장) — 파일을 읽고 분석만 합니다.
  - *파일 수정 허용* — Claude가 파일을 만들거나 고칠 수 있습니다. 꼭 필요할 때만!
  - *직접 지정* — Claude Code의 `--allowedTools` 형식 (예: `Read,Bash(npm test)`)

## 데이터는 어디에 저장되나요?

전부 이 폴더 안 `data/` 에 사람이 읽을 수 있는 형태로 저장됩니다.

| 파일 | 내용 |
|---|---|
| `data/sessions.json` | 모든 실행 기록 |
| `data/reports/*.md` | 일일 리포트 (마크다운) |
| `data/buttons.json` | 자동화 버튼 목록 |
| `data/config.json` | 설정 (작업 폴더·슬랙·스케줄) |
| `data/todos.json` `events.json` `notes.json` | 할 일 / 일정 / 메모 |
| `data/focus.json` | 집중 타이머 기록 |

백업하려면 `data/` 폴더만 복사하면 됩니다.

## 자주 묻는 질문

- **버튼이 "실패"해요** → 왼쪽 아래 상태등이 주황색이면 Claude Code 미설치/미로그인입니다. 위 "최초 1회 설정" 참고.
- **여러 명이 같이 써도 되나요?** → 이 앱은 각자 컴퓨터에서 실행하는 개인용입니다 (보안을 위해 내 컴퓨터에서만 접속 가능하도록 잠겨 있어요).
- **포트를 바꾸고 싶어요** → `PORT=9000 node server.js` 처럼 실행하세요.
- **작업이 너무 오래 걸려요** → 기본 15분에서 자동 중단됩니다. 콘솔의 "중단" 버튼으로 언제든 멈출 수 있어요.
